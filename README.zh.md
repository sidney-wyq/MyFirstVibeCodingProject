# MyFirstVibeCodingProject（中文说明）

一个小型 Python 项目，通过清晰、可运行的示例演示 Python 的基本数据类型与控制语句。

## 项目内容

- `basic_demo.py` — 单文件示例，包含：
  - **基本数据类型**：`int`、`float`、`complex`、`bool`、`str`、`list`、
    `tuple`、`dict`、`set`、`None`，以及类型转换。
  - **控制语句**：`if / elif / else`、三元表达式、`for` 循环配合 `range`、
    `while` 循环、`break` / `continue`、嵌套循环、`for-else`、`match`
    （Python 3.10+），以及 `enumerate` / `zip`。

## 环境要求

- Python 3.10 及以上（`match` 语句需要 3.10+）。

## 使用方法

在项目根目录运行：

```bash
python basic_demo.py
```

脚本会打印上述所有数据类型与控制语句的演示结果。
