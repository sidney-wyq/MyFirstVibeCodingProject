# MyFirstVibeCodingProject

A small Python project that demonstrates Python's fundamental data types and
control-flow statements through readable, runnable examples.

## Contents

- `basic_demo.py` — A single-file demo covering:
  - **Basic data types**: `int`, `float`, `complex`, `bool`, `str`, `list`,
    `tuple`, `dict`, `set`, `None`, plus type conversions.
  - **Control statements**: `if / elif / else`, ternary expressions, `for`
    loops with `range`, `while` loops, `break` / `continue`, nested loops,
    `for-else`, `match` (Python 3.10+), and `enumerate` / `zip`.

## Requirements

- Python 3.10 or newer (the `match` statement requires 3.10+).

## Usage

Run the demo from the project root:

```bash
python basic_demo.py
```

The script prints examples of every data type and control statement described
above.
